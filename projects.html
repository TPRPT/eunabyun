Data Mining

What drives YouTube view counts?YouTube 조회수에 영향을 주는 요인

Python · Regression · Random forest · Statistical analysis

Compared regression and tree-based models using US trending-video data, examining how feature availability and evaluation choices affect the results.미국 트렌딩 영상 데이터로 회귀 모델과 트리 기반 모델을 비교하고, 변수의 이용 가능 시점과 평가 방식이 결과에 미치는 영향을 살펴봤습니다.

Approach & limitations접근 방법과 한계

The analysis distinguishes upload-time predictors from later engagement signals and examines random versus temporal evaluation. The dataset covers trending videos, so the findings do not represent all uploaded videos.업로드 시점 변수와 이후의 반응 지표를 구분하고 무작위 분할과 시간 기준 평가를 검토했습니다. 트렌딩 영상으로 한정된 데이터이므로 전체 업로드 영상으로 결과를 일반화하기 어렵습니다.

Deep Learning

Cafe table occupancy classification카페 테이블 사용 여부 분류

Python · PyTorch · CNN · ResNet18

Implemented a CNN and fine-tuned an ImageNet-pretrained ResNet18 to classify cafe table images as empty or occupied.카페 테이블 이미지의 빈자리 여부를 분류하는 CNN을 구현하고 ImageNet 사전학습 ResNet18을 fine-tuning했습니다.

Approach & limitations접근 방법과 한계

The dataset contains 230 images, with 158 for training, 35 for validation and 37 for testing. I compared learning curves and classification errors. The small test set limits conclusions about performance in new cafes.230장의 이미지를 학습 158장, 검증 35장, 테스트 37장으로 나눠 학습 곡선과 분류 오류를 비교했습니다. 테스트 표본이 작아 새로운 카페에서의 성능은 추가 검증이 필요합니다.
